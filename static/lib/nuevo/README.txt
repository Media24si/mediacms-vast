Set of plugins for Videojs framework by Nuevodevel.com

The video.js player file used in `examples` directory is "video.js" or minimized version "video.min.js", located in the "videojs" directory.
This is video.js version 8.20.0 released 2024-11-19.
Full version of the videojs JavaScript file is located in the same directory.


You may also use any CDN hosted video.js version 7.x or 8.x. 


Upload "videojs" directory to your server.
Enter the license key for your domain in the file "license.js"

Navigate to "videojs/examples/index.html" for multiple HTML examples of videojs and Nuevo plugin, covering the most popular videojs and nuevo plugin usage.


IMPORTANT
=========

If you used one of examples before updating the license key you will need to clear browser's cache.
Clearing cache for your website page is possible by using some simple hotkeys:

    Windows and Linux browsers: CTRL + F5
    Apple Safari: SHIFT + Reload toolbar button
    Chrome and Firefox for Mac: CMD + SHIFT + R
